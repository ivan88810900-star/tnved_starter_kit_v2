## Оставшиеся расхождения и границы

В официальном указателе группы 41 первая буква «Hеобработанные» — Latin H;
в PDF/принятой редакции — Cyrillic Н. Навигационный заголовок следует указателю;
факт различия сохранён без ручной выдуманной нормализации. Это остающийся
конфликт написания между источниками, не потеря кодов.

Внутри проверенных структурных таблиц всех 96 групп остающихся расхождений
кандидат/HTTP не найдено. Проверка привязана к указанным байтам, не ко всем
будущим публикациям. Координатный метод проверен данным корпусом; изменённая
вёрстка требует новой сверки. Условия действия, поправки по датам, ставки/НДС/
NTM и юридическая полнота этим результатом не подтверждаются. UI показывает
«Источник не проверен» / «Подтверждённые ставки отсутствуют».

Независимая A5 не выполнялась: новые агенты запрещены владельцем. Авторские
проверки не выдаются за независимую A5. A6 не вызывался. Сохранены DB HOLD и
запреты merge/deploy/enforcement; постоянная БД и backup не затронуты.
Новых агентов/чатов/расписаний нет. Использована штатная lease generation 446;
исторические записи ownership не очищались; отклонённый TASK_BOARD write
не повторялся. Scope: комментарии #257 6684037159, 6684272194, 6684616302.
