# Предварительный расчёт из карточки

На подготовленном Mac откройте локальный справочник на порту 18016, найдите код 3304100000 и нажмите «Открыть калькулятор». Введите стоимость 100000 RUB и ручную пошлину 7,55 %. В строке пошлины появятся 7 550 ₽ и основание «Вручную». К оплате итог не определён. При пустой ставке сумма пошлины отсутствует. Явный ноль даёт ручную пошлину 0 ₽. Ссылка «Вернуться к карточке» возвращает к выбранной позиции. Для просмотра справочного значения и страницы тарифа откройте «Подробнее о товаре».

Профиль проверяет существование конечного товара в закреплённом снимке при каждом расчёте. Родительскую группу, неактивную отметку или отсутствующий код использовать нельзя. Ставки архива, включая комбинированные, остаются справочными. Они не заполняют поле ручного ввода. Поиск архивных карточек ТР доступен из карточки товара по раскрытию «Нетарифные требования». Для предметного заключения нужны характеристики товара, действующий нормативный источник и документ на продукцию.

Для запуска здесь используется ветка agent/local-catalog-payments-v1. Из корня Tariff:

```bash
cd catalog-payments-worktree/customs-clear/frontend
VITE_TARIFF_LOCAL_PILOT=1 /Users/fl/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node node_modules/vite/bin/vite.js build
bash ../backend/scripts/run_local_catalog_pilot.sh
```

Процесс слушает только 127.0.0.1. Папка r466/data уже подготовлена. Профиль проверяет её контрольные суммы, читает структурный снимок и семь глав в режиме read-only. Таблица из девяти публичных архивных карточек копируется во временный каталог. Для работы существующего расчётного движка в этой временной копии создаётся пустая схема, после чего соединения работают в режиме SQLite query_only. История, административные операции и загрузчики в профиль не включены. Остановка обычного процесса через Ctrl+C завершает стенд.

## Воспроизведение по опубликованному коду

Исходный кандидат глав 30–40 — `615fae7c46cfe93d7f55299838ed551362da8dce`. В нём 944 справочные записи. Для проверки нужны отдельно предоставленные изолированные SQLite, включая 7 глав в основном каталоге, главу 37 в дополнительном и 9 частей глав 38–40. Хеши перечислены в `customs-clear/backend/data/local_pilot_pins.json`. Код и шаблон запуска доступны без этих данных.

На чистой проверочной машине подготовьте Python 3.12 и Node 24.22.3. В каталоге frontend выполните `npm ci` по зафиксированному package-lock.json и `VITE_TARIFF_LOCAL_PILOT=1 npm run build`. В каталоге backend установите в отдельную среду `python -m pip install -r requirements-local-pilot.txt`. На подготовленном Mac используются уже установленные зависимости и PYTHONPATH из scripts/run_local_catalog_pilot.sh.

В `data/local_pilot_profile.example.json` заданы относительные пути от корня с локальными данными. Для другой структуры скопируйте шаблон и измените пути. Команды из каталога backend используют TARIFF_WORKSPACE с абсолютным путём к этому корню.

```sh
python -m app.local_pilot_profile --config data/local_pilot_profile.example.json --root "$TARIFF_WORKSPACE" --port 18017
```

Откройте http://127.0.0.1:18017/tnved и найдите 4012110000. В карточке видна комбинированная ставка со ссылкой на страницу 10. В другом терминале из backend выполните:

```sh
python -m unittest tests.test_local_pilot_profile tests.test_local_pilot_payments
python tests/local_pilot_smoke.py --config data/local_pilot_profile.example.json --root "$TARIFF_WORKSPACE" --port 18017
```

Вторая проверка сравнивает две реальные строки HTTP с закреплёнными SQLite, три ручных расчёта и защищённый маршрут. Остановите процесс переднего плана сочетанием Ctrl+C.

## Отдельный профиль штатного входа

Опция `--auth-file` предназначена для отдельного процесса на 127.0.0.1 после решения владельца. Допустимый файл — JSON вне Git, принадлежащий текущему пользователю, с режимом 0600. Он содержит SECRET_KEY для HS256 и три пароля штатных пользователей в ADMIN_PASSWORD, VIEWER_PASSWORD и DECLARANT_PASSWORD. Подставлять реальные значения в репозиторий не требуется.

При выборе этого профиля штатные login, me и logout доступны под /api/auth. Штатная зависимость require_authenticated_user проверяет Bearer JWT или HttpOnly-cookie для POST /api/non_tariff/normative-block. Для локального HTTP cookie называется tariff_pilot_session, использует путь /api и SameSite Strict. Учетная запись test в этом процессе отключена. Профиль не принимает ADMIN_API_TOKEN или настройки постоянной БД.

После согласования приёмка начинается со входа через существующую форму, запроса me, обращения к защищённому маршруту, выхода и проверки запроса без сессии. На данном кандидате нормативный маршрут после успешной авторизации всё ещё отвечает 503. Для содержательного ответа нужны отдельное подключение предметного обработчика, подтверждённые сведения о товаре, редакция нормы и проверяемый документ.
