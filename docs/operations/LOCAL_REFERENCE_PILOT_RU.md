# Предварительный расчёт из карточки

На подготовленном Mac откройте локальный справочник на порту 18016, найдите код 3304100000 и нажмите «Открыть калькулятор». Введите стоимость 100000 RUB и ручную пошлину 7,55 %. В строке пошлины появятся 7 550 ₽ и основание «Вручную». К оплате итог не определён. При пустой ставке сумма пошлины отсутствует. Явный ноль даёт ручную пошлину 0 ₽. Ссылка «Вернуться к карточке» возвращает к выбранной позиции. Для просмотра справочного значения и страницы тарифа откройте «Подробнее о товаре».

Профиль проверяет существование конечного товара в закреплённом снимке при каждом расчёте. Родительскую группу, неактивную отметку или отсутствующий код использовать нельзя. Ставки архива, включая комбинированные, остаются справочными. Они не заполняют поле ручного ввода. Поиск архивных карточек ТР доступен из карточки товара по раскрытию «Нетарифные требования». Для предметного заключения нужны характеристики товара, действующий нормативный источник и документ на продукцию.

Для запуска здесь используется ветка agent/local-catalog-payments-v1. Из корня Tariff:

```bash
cd catalog-payments-worktree/customs-clear/frontend
VITE_TARIFF_LOCAL_PILOT=1 /Users/fl/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node node_modules/vite/bin/vite.js build
bash ../backend/scripts/run_local_catalog_pilot.sh
```

Процесс слушает только 127.0.0.1. Папка r466/data уже подготовлена. Профиль проверяет её контрольные суммы, читает структурный снимок и семь глав в режиме read-only. Таблица из девяти публичных архивных карточек копируется во временный каталог. Для работы существующего расчётного движка в этой временной копии создаётся пустая схема, после чего соединения работают в режиме SQLite query_only. История, административные операции и загрузчики в профиль не включены. Остановка обычного процесса через Ctrl+C завершает стенд.
