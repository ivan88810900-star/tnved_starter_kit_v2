## Изменение обработки

Текстовая проекция отделена от сохранённых исходных строк. Лексический дефис
сохраняется, лишний пробел на границе переноса убирается. Висячие конструкции
«газо- или», «...- и» остаются раздельными. `-либо` без исходного разделителя
остаётся суффиксом: «какого-либо», а не ложной висячей конструкцией.

Для разрыва внутри слова без дефиса требуется **совпавшая посимвольная строка
PDF и отсутствие реального пробельного символа на её конце**. Одна лишь близость
к правой границе или словарь недостаточны. Пробел после последнего слова может
находиться за номинальной границей колонки; он включается по границе самого
печатного слова, чтобы не склеить «менее 0,94» и обычные слова групп 39/70.
Неизвестный разделитель не угадывается; сборка требует проверенных границ.

Так исправлены и «изобензофуран», «метилендициклогексилдиизоцианата», а также
дополнительно обнаруженный разрыв «холодопроизводительность|ю». Подстановок по
конкретному HS-коду нет. Удаление печатного дефиса как орфографического переноса
не выполняется: это отдельная семантическая нормализация.

Всего изменены 472 подписи: 453 подтверждённые строки из списка Claude и 19
дополнительных по тем же правилам. Для всех 453 проверено точное вхождение
ожидаемых compound words; `9027` - отдельный отрицательный контроль. Для всех
исходных строк проверены посимвольные границы, неизвестных границ в этом корпусе
нет. Все 21090 физических active/codeless/caption строк независимого реестра
повторно сопоставлены A0 с новым кандидатом по identity/parent/order/page/kind/
depth. Это не только равенство общей численности.

В **том же новом SQLite-кандидате** добавлена source-text projection с
raw_label, raw_lines/page/baseline/характерным разделителем и dash_depth.
Коды, node IDs, родители, порядок, source hash/page, captions, aliases и reserved
решения сохраняются. Старые DB/архив аудита не переписываются. API возвращает
raw_name/source_lines/dash_depth/kind. UI показывает реальное число тире,
caption без тире; раскрытие и бескодовые IDs сохраняются. Исходный текст доступен
для аудита отдельно от исправленного имени и полного path.
